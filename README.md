# 🌍 Europe Weather Analytics Pipeline

## 📌 Project Overview

This project demonstrates an end-to-end Data Engineering pipeline that extracts weather data from the Open-Meteo API, stores it in Amazon S3, catalogs and transforms the data using AWS Glue, and visualizes insights through Power BI.

The project showcases API integration, cloud storage, ETL processing, data cataloging, and dashboard development using AWS services.

---

## 🏗️ Architecture

Open-Meteo API
↓
Python (Data Extraction)
↓
Amazon S3 (Raw Data)
↓
AWS Glue Crawler
↓
AWS Glue Data Catalog
↓
AWS Glue ETL Job
↓
Amazon S3 (Processed Data)
↓
Power BI Dashboard
